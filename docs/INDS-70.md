# INDS-70 — Network topology

Open **Topology** in the dashboard. The map shows the upstream router, INDS
bridge, and guest access point alongside the observed device inventory.
Select a node for details, or open a device's investigation page from the map.

Search by hostname, IP, or MAC address. Filter for recently seen devices or
devices with active incidents. Recently seen means observed within five minutes.

The backbone represents the deployment layout. The gateway API reports bridge
health, and the device API supplies inventory. Individual Wi-Fi associations
and physical links are unverified.

Verified in Edge at desktop and mobile widths with an isolated SQLite inventory.
